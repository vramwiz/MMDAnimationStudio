# Saved poses

Codexが作成したポーズを、MMD AI Previewで3D確認するための格納先です。

- 保存形式はJSONです。
- `pose_data`はMMD共通の`mmd.pose`バージョン1です。
- Codexから`present_pose`を受けると、画面へ提示する前にこのフォルダへJSONを作成します。
- アプリ左側の一覧でJSONを選ぶと、そのポーズをプレビューへ反映します。
- 起動時は更新日時が最も新しいJSONを自動選択します。
- PMXの絶対パスは保存しないため、Gitで別環境へ同期できます。
- 同名のファイルがある場合は`-2`、`-3`のような連番になり、既存ファイルを上書きしません。
